## The listing process

1. Inspect every supplied photograph, including tag, back, sleeves and flaws. Read seller notes as evidence, while separating merchandising buckets from manufacturers. In this inventory, `Brand: Streetwear` is often a bucket.
2. Record useful facts with support: inventory field and supporting words, or photo number and visible/readable detail. Prioritize identity, garment type, maker, date/era, graphic, construction, material, size and alterations. Evidence notes are model-produced review aids, not independent verification.
3. Form two to four plausible buyer phrases. These are editorial hypotheses, not measured search-volume data. Cover a specific identity and relevant broader garment/subject/style intent.
4. Compose a readable title around the strongest supported identity and exact item type. Add useful era, color or distinctive graphic when established. Do not repeat synonyms merely to lengthen it. A date printed on a design can identify an event without proving manufacture year.
5. Write two or three concise sentences that add details beyond the title. Preserve valuable seller facts. Include supplied measurements exactly; never infer fit or measurements from a flat photograph. Disclose documented alterations and flaws. A used-condition grade alone does not establish fading, stains or holes.
6. Select attributes individually. Manufacturer, graphic subject and license holder are distinct concepts. Return the actual maker even when absent from the prompt's brand hints; the server resolves the full template. Unmatched or ambiguous names become Other plus a review warning. Do not turn American Vintage into a generic vintage classification.
7. Use five distinct, relevant hashtags. Include the most useful actual identity, subject, item type or supported style. No unrelated popular brands, invented eras or generic tag padding.
8. Review the photos, evidence notes, copy, attributes, price and export before approval. Fix uncertain facts rather than simply accepting a polished sentence.

The standard store footer, size line, FREE shipping, signature, SKU and banned-word rules remain in the application. No Instagram line is inserted. Measurements would improve buyer information; the current request-for-measurements footer is not a substitute for actual measurements when available.

## Implemented changes and retained decisions

- New generations distinguish a readable tagged size from an unverified seller-provided size, without calling an unseen tag missing.
- Generation now returns inspectable evidence and buyer phrases along with listing copy. The prompt requests fact extraction before composition and useful factual coverage rather than simply paraphrasing the item name.
- Brand hints no longer restrict the output to a short maker list. Exact/normalized unambiguous maker names resolve against the complete template; no fuzzy guess silently assigns a different brand.
- Structured generation constrains category, color, age and styles to template values. Unknown era is blank, not a 90s fallback. Explicit inventory era conflicts and non-sweatshirt categories for crewneck inventory block approval and export, including previously approved drafts. Server approval writes enforce the same checks. Unrecognized dropdown values show an explicit invalid-value placeholder instead of silently selecting the first option. Duplicate hashtags are blocked by review validation.
- Secondary color, Source 1 and Style 3 are visible and editable. Blank values remain blank in the CSV. Age can be left unspecified during review.
- The previously requested Multi / Vintage / Y2K defaults are retained as initial values for compatibility, with a visible warning. They are not endorsed as universal SEO choices. Recommendation: use only where relevant and remove unsupported defaults per item. Changing the shop-wide policy should be an explicit decision.
- Older cached drafts are marked. Deployment does not rewrite their copy. Normal Analyze clicks still return cached results without another paid call.
- An explicit single-item **Generate replacement draft (uses API credits)** action replaces copy/analysis and clears approval after success. Failure retains the saved draft. Exported items cannot be replaced through this action. It uses the existing configured model; the output allowance is increased from 1,800 to 2,600 tokens to accommodate evidence. No second automatic review call was added.
- All CSV exports use the template’s exact city-level value `Atlanta, United States` (Atlanta, GA), including re-exports of saved approved items. Inventory storage notes do not override the shipping origin. Already imported Depop drafts/listings are not updated automatically.
- Price formulas, shipping charges and photographic delivery are unchanged. This release does not compare every item with sold-market prices.

## Release gate before scaling

The software checks validate state transitions and data handling, not whether a listing will rank or sell. No paid production generation or private live-dashboard verification was performed for this change.

Pilot five representative items: AJ1060 (date/text graphic), AJ1030 (brand/event/embroidery), AJ1031 (alteration), AJ1029 (ambiguous identity) and AJ1028 (subject/manufacturer distinction). Use the replacement action only for unexported drafts you want rewritten; previously exported copies can be compared manually.

Accept a pilot item only when all of the following are true:

- No unsupported maker, era, material, graphic identity, fit, condition or origin claim.
- No missing important identity, distinctive feature, documented flaw or alteration.
- Title reads naturally and the body adds useful information rather than filler.
- Attributes and five hashtags are relevant to this particular item; generic defaults have been checked.
- Size, price, shipping, cover order and description are consistent with the item and shop settings.

A critical factual error or omitted alteration fails the item regardless of how good the prose sounds. Correct the common cause before processing the remaining batch. Review actual generated outputs; mock responses and automated tests cannot substitute for this step.

After publication, evaluate listing views, engagement and sales over comparable periods and cohorts. Personalization and uncontrolled differences mean one manual search or one quick sale cannot establish a causal SEO improvement.
